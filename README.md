## Verifikasi Integritas Berkas

Setelah mengunduh berkas (dan menarik objek Git LFS jika menggunakan `git lfs`), verifikasi *checksum* SHA-256 dengan:

```bash
sha256sum -c SHA256SUMS.txt

```
